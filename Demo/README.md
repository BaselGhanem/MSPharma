# SupplyFlow — العرض التفاعلي بالعربية

صفحة مستقلة لشرح رحلة تخطيط التوريد في مصانع الأدوية، من استقبال الطلب حتى MPS وMRP والمتابعة.

## فتح العرض
- شغّل الملف `Demo/index.html` في المتصفح بعد تنزيل المستودع، أو انشر المستودع بواسطة GitHub Pages ثم افتح مسار `/Demo/`.
- العرض مستقل عن ملفات النظام؛ كل ملفات العرض موجودة داخل `Demo/`.
- لتفعيل الخط العربي **Almarai** عند الفتح يلزم اتصال بالإنترنت لتحميله من Google Fonts. عند تعذر ذلك تظهر الخطوط البديلة.
- زر **افتح النظام** ينتقل إلى `../index.html` في نفس الاستضافة.

## أدوات التقديم
- **التالي / السابق** للتنقل بين 25 محطة.
- **تشغيل تلقائي** يبدّل الشرائح كل 24 ثانية، ويمكن إيقافه بأي وقت.
- **نص المقدم** لعرض حديث عربي جاهز لكل محطة (يمكن إخفاؤه أمام العميل).
- **فهرس العرض** للانتقال مباشرة لأي محطة.
- **ملء الشاشة** لعرض الشاشة بشكل نظيف أمام العميل.
- **الحساب المباشر** ضمن محطة Net Requirements: تغيير Forecast وOrders وSafety وFG وIncoming يحدث الناتج فوراً.

## اختصارات لوحة المفاتيح
| المفتاح | الوظيفة |
|---|---|
| السهم لليسار / Space / Page Down | التالي |
| السهم لليمين / Page Up | السابق |
| Home / End | أول / آخر شريحة |
| N | إظهار أو إخفاء نص المقدم |
| F | ملء الشاشة |
| Escape | إغلاق النوافذ |

## النشر عبر GitHub Pages

من المستودع `BaselGhanem/MSPharma` افتح:

`Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save`

بعد تفعيل GitHub Pages سيكون المسار المتوقع:

`https://baselghanem.github.io/MSPharma/Demo/`

الرابط أعلاه يعتمد على تفعيل خدمة Pages وإتمام النشر، وليس رابطاً مؤكداً قبل ذلك.

## نطاق التنفيذ

**لم يجرِ تعديل ملفات النظام الأصلية.** أضيفت فقط ملفات العرض `Demo/index.html` و`Demo/styles.css` و`Demo/app.js` و`Demo/README.md`.

الشرح يميز بين إصدار خطة MPS وبين الإفراج النوعي من QA، ويعرض MRP كإشارات للاحتياج والمتابعة وليس كأوامر شراء تصدر تلقائياً.
